# 大模型综合使用成本(国内)

> 编程场景 · 缓存命中率加权 · 订阅价格折算

汇总各家 LLM 官方 API 价格，与 Coding Plan 订阅、中转站等渠道换算价格，按编程场景实际用量比例加权，综合对比成本。

---

- **加权综合价** — 长上下文编程任务，结合各厂商缓存命中率加权
- **订阅渠道换算** — 官方与第三方订阅，按额度或积分折算优惠单价
- **人民币折算** — 美元、积分统一折算为 ¥，自动标出最优渠道
- **模型思考效率（未计入）** — 各模型思考努力程度、任务复杂度不同，无法量化计入
